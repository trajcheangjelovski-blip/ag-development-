# Demo website photos — where to put them

Each demo now shows a real photo wherever you drop a matching file in this folder.
Until a file exists, the spot shows a clean gradient (so nothing ever looks broken).

Just download your images (e.g. from Freepik, under your own Freepik license),
rename them to the names below, and drop them in the matching folder.
Re-deploy (`./deploy.sh`) and the photos appear.

Tip: keep files reasonably small (run them through tinypng.com) so pages stay fast.

---

## restaurant  →  public/demos/restaurant/
- `hero.jpg`        — wide background behind the title (food / cozy interior). ~1600×900
- `about.jpg`       — square image in the "Our Story" section. ~800×800
- `gallery-1.jpg` … `gallery-8.jpg` — square photos for the gallery grid (dishes, interior). ~600×600
  (Freepik search ideas: "italian food", "pasta plate", "restaurant interior", "pizza")

## dental  →  public/demos/dental/
- `hero.jpg`        — main hero image (smiling patient / modern clinic). ~1000×750
- `team-1.jpg`, `team-2.jpg`, `team-3.jpg` — square staff portraits. ~600×600
  (Freepik search ideas: "dentist", "dental clinic", "doctor portrait")

## fitness  →  public/demos/fitness/

- `trainer-1.jpg` … `trainer-4.jpg` — portrait (tall) coach photos. ~600×800

## store  →  public/demos/store/
- `hero.jpg`        — tall image on the right of the hero (fashion / model). ~800×1000

---

### A note on Freepik
Freepik images must be downloaded through your own account and used per their license
(free tier usually needs attribution; Premium does not). Don't paste Freepik page URLs
into the code — they won't display. Download the actual image file and place it here.

If you'd rather use photos that need no download and no attribution, ask AG Development
to switch the demos to Unsplash/Pexels images (both allow direct embedding).
